Política de Privacidade

O Caçador de Boletos

O Caçador de Boletos é uma extensão de produtividade desenvolvida para auxiliar os usuários a localizar, organizar e copiar linhas digitáveis de boletos exibidos em telas ativas (como WhatsApp Web e Gmail) ou em arquivos PDF fornecidos voluntariamente pelo usuário.

1. Processamento 100% Local (Zero Coleta)

Toda a leitura, análise de texto e extração de códigos de barra são realizadas exclusivamente dentro do seu próprio navegador. Nenhum dado pessoal, histórico de navegação, mensagens ou informações financeiras são transmitidos, enviados ou armazenados em servidores externos.

2. Permissões do Navegador

A extensão solicita apenas as permissões estritamente necessárias para o seu funcionamento:

  • activeTab / scripting: Utilizados exclusivamente no momento em que o usuário clica no botão de busca para analisar o texto visível na tela ativa.
  • sidePanel: Utilizado para apresentar os resultados em uma interface lateral organizada.
  • storage: Utilizado para armazenar localmente no seu computador a contagem de usos e o status da sua licença de uso.

3. Compartilhamento e Não Comercialização

Nós não vendemos, alugamos, compartilhamos ou transferimos quaisquer dados de usuários para terceiros. Não utilizamos dados para fins publicitários ou de análise de crédito.

4. Contato

Caso tenha dúvidas sobre esta política de privacidade, entre em contato pelo e-mail de suporte oficial.
